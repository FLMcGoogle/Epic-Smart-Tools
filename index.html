01 · Reusable content
03 / 09
SmartPhrase

A shortcut that expands into reusable content. It can include text, SmartLists, SmartLinks, NoteWriter forms, and linked images.

Use it when: “I type this all the time.” Users may maintain personal phrases; builders may maintain system phrases.

Clinical example.CHFPLAN
Heart failure plan
Most recent EF: [SmartLink]
NYHA class: [SmartList]
Daily weights discussed.
Follow-up in _____ weeks.

The phrase is the package and launch point. The embedded tools do the selecting and retrieving.

SmartPhrases are flexible and text-heavy. A phrase itself does not store discrete data, though an embedded SmartList may.
02 · Structured choices
04 / 09
SmartList

A menu of predefined options placed inside a note or another SmartTool. The clinician moves through choices rather than free-texting.

Use it when: “I want the clinician to pick from standardized answers.” Lists can be optional and may be configured to store SmartData.

Clinical examplePick one
Smoking status:
{ Never | Former | Current }

Follow-up:
{ 1 week | 2 weeks | 1 month | PRN }
⚠Governance matters: similar lists multiply quickly. Check where a list is used before editing it, and coordinate any reportable data choices.
Standardization → structured documentation → potentially reportable information.
03 · Existing information
05 / 09
SmartLink

A live pull of information Epic already knows. SmartLinks can display patient information or bring other content into a workflow.

Use it when: “Epic already has this information - do not make me type it again.” Context and parameters determine what appears.

Clinical exampleLive data
Patient: [preferred name]
Most recent A1c: [result]
Current medications: [medication list]
Recent vitals: [vital signs]
⚠Less can be more: too many data pulls can create note bloat. Include information that helps the reader make a decision.
SmartPhrase inserts reusable content; SmartLink retrieves information already in Epic.
04 · Centrally managed content
06 / 09
SmartText

A builder-created block of approved content that can contain words, SmartLists, SmartLinks, and images.

Use it when: “The organization wants everyone starting from the same centrally managed template.” It may be selected manually, included in a SmartSet, defaulted, or chosen by a rule.

Clinical exampleOrganization standard
Central line procedure note
Indication: [SmartList]
Site: [SmartList]
Ultrasound guidance: [SmartList]
Number of attempts: _____
Complications: [SmartList]

The key distinction is control and deployment: builders maintain the shared starting point.

SmartText and SmartPhrase can contain similar ingredients; ownership and deployment are the practical differentiators.

SmartTools are building blocks.

A useful note often combines several tools, each doing the job it does best.

1

Launch

Type a SmartPhrase such as .OHCHF.

2

Retrieve

SmartLinks pull the latest EF and medication list.

3

Choose

SmartLists capture NYHA class and follow-up.

4

Standardize

SmartText supplies approved plan language when needed.

.OHCHF → Most recent EF: [SmartLink] · NYHA class: [SmartList] · Treatment plan: [SmartText]
Data + choices + standardized content, packaged in a shortcut.
